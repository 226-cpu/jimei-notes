- **两个大局**同步交织、相互激荡：民族复兴战略全局 + 世界百年未有之大变局，彼此互为背景与动力。
- **新时代**最重要依据是<span class="术语">社会主要矛盾转化</span>，不是单一经济指标变化。
- **新时代**可从五个维度理解：历史脉络、实践主题、人民性、民族性、世界性（对应笔记中五个“是……的时代”）。
- **两个结合**是推进马克思主义中国化时代化的<span class="术语">根本途径</span>：中国具体实际 + 中华优秀传统文化（后者是创新理论的“根”）。

### 二、时代课题：“时代三问”各管什么？

| 课题 | 着力点 |
|------|--------|
| 坚持和发展什么样的中国特色社会主义、怎样坚持 | **方向性质** |
| 建设什么样的社会主义现代化强国、怎样建设 | **目标路径**（2020 小康 → 2035 基本现代化 → 本世纪中叶强国） |
| 建设什么样的长期执政马克思主义政党、怎样建设 | **力量保证** |

### 三、主要内容：三块各是什么角色？

- **十个明确**：核心要义、基本精神（“是什么”，偏理论内涵）。
- **十四个坚持**：基本方略、实践要求（“怎么做”，落实思想的基本方略）。
- **十三个方面成就**：新时代伟大实践成就，既体现思想指导，又反过来丰富发展思想。

### 四、方法论与地位

- **六个必须坚持**：世界观、方法论层面的“基本点”，有机整体，推进理论创新也要坚持。
- **历史地位**四句话可记：**当代马克思主义 / 二十一世纪马克思主义**、**中华文化时代精华**、**新的飞跃**、**两个确立**（决定性意义）。
