> **一、习近平新时代中国特色社会主义思想的创立** 

  - 时代背景：“两个大局”同步交织、相互激荡

   <span class="术语">“两个大局” -- 中华民族伟大复兴的战略全局世界百年未有之大变局</span>

::: info 主要内容
      当前，世界百年未有之大变局加速演进，我国发展进入战略机遇和风险挑战并存、不确定难料因素增多的时期，
      两者同步交织、相互激荡。

当前<span style="color: #2563eb">国际格局和国际体系</span>正在发生深刻调整。

<span style="color:#2563eb">全球治理体系</span>正在发生深刻变革

<span style="color: #2563eb">国际力量对对比</span>正在发生近代以来最具革命性的变化   

世界范围呈现出<span style="color: #2563eb">影响人类历史进程和趋向</span>的重大态势

:::

::: warning 中华民族伟大复兴正处于关键时期
- 中华民族迎来从站起来、富起来到强起来的伟大飞跃，中华名字伟大复兴进入不可逆转的历史进程中。

- 中华民族伟大复兴，是造成世界百年未有之大变局的重要原因；世界面临百年未有之大变局，给中华民族伟大复兴带来重大基于。
:::

  - <span style="color: #c0392b">**历史方位：中国特色社会主义进入新时代**</span>

::: danger 社会主要矛盾变化是进入新时代的重要依据
<span style="background: #fef08a; padding: 0 4px;">我国社会主要矛盾转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。</span>

:::

::: info 新时代是怎么样的时代
- 历史脉络

    是承前启后、继往开来、在新的历史条件下继续<span style="background: #fef08a">夺取中国特色社会主义伟大胜利</span>的时代。

- 实践主题

    是决胜全面建成小康社会、进而<span style="background: #fef08a">全面建设社会主义现代化强国</span>的时代。

- 人民性

    是全国各族人民团结奋斗、<span style="background: #fef08a">不断创造美好生活、逐步实现全体人民共同富裕</span>的时代。

- 民族性

    是全体中华儿女同心、奋力<span style="background: #fef08a">实现中华民族伟大复兴中国梦</span>的时代。

- 世界性

    是我国不断<span style="background: #fef08a">为人类做出更大贡献</span>的时代。

:::

::: warning 进入新时代的意义
- 从中华民族复兴的历史进程看

    意味着中华民族迎来了站起来、富起来到强起来的伟大飞跃。

- 从科学社会主义发展的进程看

    科学社会主义在21世纪的中国焕发出强大生机活力

- 从人类文明进程看

    扩展了发展中国家走向现代化的途径，为解决人类问题贡献了中国指挥和中国方案。
:::


  - 实践基础：历史性成就、历史性变革
::: info 新时代十年
- 全面加强党的领导
- 对新时代党和国家事业发展做出科学完整的战略部署
- 经过接续奋斗实现了小康这个中华民族的千年梦想
- 提出并贯彻新发展理念
- 以巨大的政治勇气全面深化改革
- 实行更加积极主动的开放战略
- 坚持走中国特色社会主义政治发展道路
- 确立和坚持马克思主义在意思形态领域指导地位的根本制度
- 深入贯彻以人民为中心的大战思想
- 坚持绿水青山就是金山银山的理念
- 确立党在新时代的强军目标
- 全面准确推进“一国两制”实践实践
- 深入推进全面从严治党
:::

  - 根本途径：“两个结合”

> 把马克思主义基本原理同中华优秀传统文化相结合
