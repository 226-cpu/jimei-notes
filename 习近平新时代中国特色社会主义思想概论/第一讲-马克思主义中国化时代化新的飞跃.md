  - 时代背景：“两个大局”同步交织、相互激荡

   <span class="术语">“两个大局” -- 中华民族伟大复兴的战略全局世界百年未有之大变局</span>

::: info 主要内容
      当前，世界百年未有之大变局加速演进，我国发展进入战略机遇和风险挑战并存、
      不确定难料因素增多的时期，

      两者同步交织、相互激荡。

当前<span style="color: #2563eb">国际格局和国际体系</span>正在发生深刻调整。

<span style="color:#2563eb">全球治理体系</span>正在发生深刻变革

<span style="color: #2563eb">国际力量对对比</span>正在发生近代以来最具革命性的变化   

世界范围呈现出<span style="color: #2563eb">影响人类历史进程和趋向</span>的重大态势

:::

::: warning 中华民族伟大复兴正处于关键时期
- 中华民族迎来从站起来、富起来到强起来的伟大飞跃，中华名字伟大复兴进入不可逆转的历史进程中。

- 中华民族伟大复兴，是造成世界百年未有之大变局的重要原因；世界面临百年未有之大变局，给中华民族伟大复兴带来重大基于。
:::

  - <span style="color: #c0392b">**历史方位：中国特色社会主义进入新时代**</span>

::: danger 社会主要矛盾变化是进入新时代的重要依据
<span style="background: #fef08a; padding: 0 4px;">我国社会主要矛盾转化为人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾。</span>

:::

::: info 新时代是怎么样的时代
- 历史脉络

    是承前启后、继往开来、在新的历史条件下继续<span style="background: #fef08a">夺取中国特色社会主义伟大胜利</span>的时代。

- 实践主题

    是决胜全面建成小康社会、进而<span style="background: #fef08a">全面建设社会主义现代化强国</span>的时代。

- 人民性

    是全国各族人民团结奋斗、<span style="background: #fef08a">不断创造美好生活、逐步实现全体人民共同富裕</span>的时代。

- 民族性

    是全体中华儿女同心、奋力<span style="background: #fef08a">实现中华民族伟大复兴中国梦</span>的时代。

- 世界性

    是我国不断<span style="background: #fef08a">为人类做出更大贡献</span>的时代。

:::

::: warning 进入新时代的意义
- 从中华民族复兴的历史进程看

    意味着中华民族迎来了站起来、富起来到强起来的伟大飞跃。

    扩展了发展中国家走向现代化的途径，为解决人类问题贡献了中国指挥和中国方案。
:::

> **二、习近平新时代中国特色社会主义思想回答的重大时代课题**

- 新时代坚持和发展什么样的中国特色社会主义，怎样坚持和发展中国特色社会主义
::: info 主要内容
坚持和发展中国特色社会主义，是改革开放以来我们党全部理论和实践的鲜明主题。坚持和发展中国夜色社会主义是一篇大文章，如何在新的时代条件下继续把这篇大文章写下去，是必须回答好的重大课题。
:::

- 建设什么样的社会主义现代化强国，怎样给建设社会主义现代化强国
::: info 主要内容
    如何到本世纪中叶把我国建设成为现代化强国是我们党面临的一个重大时代课题。
- 2020年 曲面建成小康社会
- 2035年 基本实现社会主义现代化
- 本世纪中叶 建成富强民主文明和谐美丽的社会主义现代化强国
:::
- 建设什么样的长期执政的马克思主义政党，怎样建设长期执政的马克思主义政党
::: info 主要内容
我们党作为百年大党，如何永葆先进性和纯洁性、永葆青春活力，如何永远得到人民用户和支持，如何实现长期执政，是我们必须回答好、解决好的一个根本性问题。
:::

::: warning “时代三问”与理论之眼
三个重大时代课堂，是站在新时代历史节点上向中国共产党人剔除的“时代三问”，是理解习近平新时代中国特色社会主义思想的“理论之眼”。

<span class="术语">新时代全部理论和实践的着力点</span>
- 中国特色社会主义讲的是方向性质问题
- 社会主义现代化强国讲的是目标路径问题
- 长期执政的马克思主义政党讲的是力量保证问题
:::

> **三、习近平新时代中国特色社会主义思想的主要内容** 
- “十个明确”的核心内容
::: info 主要内容
是习近平新时代中国特色社会主义思想的核心要义和基本精神

- <span class="必背">明确中国特色社会主义最本质的特征是中国共产党领导，中国特色社会主义者制度的最大优势是中国共产党领导</span>，中国共产党是最高政治领导力量，全党必须增强“四个意识”、鉴定“四个自信”、做到“两个维护”。
- 明确坚持和发展中国特色社会主义，<span class="必背">总任务是实现社会主义现代化和中华民族伟大复兴</span>，在全面建成小康社会的基础上，分两步走在本世纪中叶建成富强民主文明和谐美丽的社会主义现代化强国，以中国式现代化推进中华民族伟大复兴。
- 明确新时代 <span class="必背">我国社会主义主要矛盾</span>是人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾，必须坚持以人民为中心的发展思想，发展全过程人民民主，推动人的全面发展、全体人民红同富裕取得最为明显的实质性进展。
- 名曲中国特色社会主义事业 <span class="必背">总体布局</span>是经济建设、政治建设、文化建设、社会建设、生态文明建设五位一体，<span class="必背">战略布局</span>是全面建设社会主义现代化国家、全面啊深化改革、全部面依法治国、全部面从严治党四个全面。
- 明确<span class="必背">全面深化改革总目标</span>是完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化。
- 明确 <span class="必背">全面推进依法治国总目标</span>是建设中国特色社会主义法治体系、建设社会主义法治国家。
- 明确必须坚持和完善社会主义基本经济制度，使市场在资源配置中起决定性作用，更好发挥政府作用，把握新发展理念，加快构建以国内大循环为主题、国内国际双循环相互促进的新发展格局，<span class="必背">推动高质量发展</span>，统筹发展和安全。
- 明确党在 <span class="必背">新时代的强军目标</span>是建设一支听党指挥、能打胜战、作风优良的人民军队，把人民军队建设成为世界一流军队。
- 明确 <span class="必背">中国特色大国外交</span>要服务民族复兴、促进人类进步，推动建设新型国际关系，推动构建人类命运共同体。
- 明确 <span class="必背">从严治党的战略方正</span>，剔除新时代党的建设总要求，全民啊推进党的政治建设、思想建设、组织建设、作风建设、纪律建设、把制度建设贯穿其中，深入推进反腐败斗争，落实管党治党政治责任，以伟大自我革命引领伟大社会革命。

<span class="术语">治党、治国、治军、改革、发展、稳定、内政、外交、国防</span>
:::
